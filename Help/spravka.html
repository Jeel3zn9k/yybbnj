2. Инструкции: как сделать, чтобы всё работало

2.1. Установка и запуск на Windows

  • Нужен включённый .NET Framework 3.5 (Windows 7/8/10/11). Если программа не запускается: 
    Панель управления → Программы и компоненты → Включение или отключение компонентов Windows → .NET Framework 3.5 (галка)
    или из командной строки (от администратора): 
    dism /online /enable-feature /featurename:NetFx3 /all
  • Скопируйте папку программы куда угодно (кроме сетевых дисков); запуск — Tablo.exe.
  • Папки obj и bin внутри исходников — мусор компилятора, их можно удалять; рабочие Lib\*.dll (4 файла) удалять НЕЛЬЗЯ.

2.2. Брандмауэр и сеть (для веб-интерфейса)

  • Разрешите порт веб-сервера (по умолчанию 8642/TCP): 
    netsh advfirewall firewall add rule name="Tablo Web" dir=in action=allow protocol=TCP localport=8642
  • Адрес машины: ipconfig; подключаться по этому IP или по localhost.

2.3. Физический пульт и эмулятор

  • Пульт подключается к COM-порту (порт задаётся в настройках); переподключение — «Сервис → Переподключить пульт» или Ctrl+F7.
  • «Сервис → Эмулятор пульта» (Ctrl+F9) шлёт те же пакеты, что физический пульт, 1 в 1 — удобен для проверки без железа.
  • Лог каждой команды физ. пульта — галка в «Режим разработчика → Логи и кадр вывода» (сеансовая, по умолчанию выкл).

2.4. Веб-интерфейс (три страницы)

  • «Режим разработчика»: задайте пароль входа (не короче 5 символов), включите веб-сервер, нажмите «Применить».
  • Включение сервера подписывается токеном, привязанным к компьютеру (DPAPI). После переноса программы на другой ПК сервер не стартует — включите его заново в режиме разработчика; в главный лог при этом пишется строка-предупреждение.
  • Страницы: /display — витрина табло, /panel — пульт оператора, /operator — полная панель (названия, эталоны, администрирование).
  • Пароль веб-оператора задаётся отдельно (там же); бездействие блокирует сессию (минуты настраиваются); одновременно пускается не более 2 устройств.
  • Поля, которые вы правите, не перетираются опросом сервера, пока в них курсор или пока правка не применена; кнопка «Обновить данные» (блок «Прочие») принудительно обновляет страницу с сервера.

2.5. Дополнительный вывод игрового времени (RS-485 / сеть)

  • Находится в «Режим разработчика» (группа «Дополнительный вывод»): галка RS-485, COM-порт (порт, занятый пультом, выбрать не даст), скорость, галка сетевой отдачи, адрес и порт UDP.
  • Шаблон кадра — в группе «Логи и кадр вывода» (кодовые слова {MODE}/{TIME}/{SIG}/{TO} — подсказка при наведении на подпись «Кадр:»); «живой кадр» виден тут же.
  • Значения применяются кнопкой «Применить» окна разработчика.

2.6. Отдача времени в vMix / UDP / файл

  • «Режим разработчика → Отдача времени (три способа)»: vMix (HTTP API), UDP (JSON), файл tablo_time.txt (+ tablo_full.json).
  • Файлы пишутся при каждом изменении картины, а также один раз принудительно при запуске программы — после старта файл сразу актуален или создаётся, если его не было.

2.7. Android-приложение (APK)

  • Проект — в папке android (инструкция: android/README-ANDROID.md).
  • Сборка: открыть папку в Android Studio → Build → Build APK(s). Если нет gradle-обёртки: gradle wrapper --gradle-version 8.4, затем gradlew assembleDebug.
  • Установка: adb install app-debug.apk или открыть APK на устройстве (разрешить установку из внешних источников). Требуется Android 8.0+ (minSdk 26).
  • В приложении укажите адрес сервера вида http://192.168.1.50:8642; вход — паролем веб-оператора; соединение без шифрования разрешено политикой приложения (локальная сеть).
  • Распространяйте APK только среди своих людей: доступ защищё паролем и лимитом устройств на сервере.

2.8. iPhone/iPad (кратко)

  • Родного приложения нет: открывайте веб-панель в Safari.
  • Обходные пути установки веб-ярлыка/оболочки: AltStore или Sideloadly (бесплатная подпись обновляется раз в 7 дней); TestFlight требует платный аккаунт разработчика ($99/год).

2.9. После отключения электричества

  • Состояние матча каждые 2 секунды снимком сохраняется в match_state.xml.
  • После резкого обрыва при следующем запуске появится окно «Произошло резкое закрытие… восстанавливаем последнюю копию матча?» с временем, периодом, счётом и эталоном; при штатном закрытии окно не появляется.

2.10. Логи и диагностика

  • remote_com_log.txt — главный журнал (команды, веб, ошибки записей); crash_log.txt — аварийные ситуации.
  • «Режим разработчика → Логи и кадр вывода»: включение журнала, лог команд пульта, живой кадр, «Очистить логи».

2.11. Пароли и сбросы

  • Пароль входа (режим разработчика) и пароль веб-оператора — разные; минимум 5 символов.
  • Супер-пароль сбрасывает пароли и останавливает сервер (кнопки в окне разработчика); файл passreset.txt не восстанавливается из копий.

3. Что умеет программа

  • Матчевое табло хоккея: периоды, счёт, удаления обеих команд, таймауты, перерыв, предматчевый отсчёт с метками сирен, овертайм, часы/заставка, видеорежим.
  • Управление: физический пульт (COM), клавиатура/мышь, веб-интерфейс (3 страницы), Android-приложение, эмулятор пульта.
  • Отдача наружу: RS-485 кадр EXT, UDP JSON, vMix HTTP API, файлы tablo_time.txt / tablo_full.json.
  • Защита: пароли с хэшами PBKDF2, сессии с токенами, лимит устройств, блокировка по бездействию, токен включения сервера с привязкой к машине, журнал неудачных входов.
  • Надёжность: автосохранение матча и восстановление после обрыва питания, атомарная запись файлов, журналы диагностики.
